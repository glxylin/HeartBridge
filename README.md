### 心橋國際（虛構設定）

心橋是一家 2024 年在台灣設立的金融科技新創公司，目前處於種子輪階段，正以少量印尼籍與越南籍移工為對象進行小規模試營運。其外籍移工國外小額匯兌業務許可證仍在金融監督管理委員會審查中，試營運期間交易透過與持照業者的合作安排辦理。團隊約 15 人。

### 要解決的問題

- 台灣有效聘僱許可的移工約 78.7 萬人，其中印尼籍與越南籍合計 53 萬 7,575 人，占 68.3%（勞動部，2026 年 5 月底）。
- 薪資匯款正快速轉向持照數位管道，但轉移並未完成：委託人力仲介代辦銀行結匯（代結匯）仍占合法匯款 39%，另有未受檢查或非法的管道，風險由移工自行承擔。
- 心橋的願景是在台灣至印尼／越南通路上，提供持照、受監理、可查核的數位匯款平台，作為合法選擇之一，同時承載規模較小的入金流（海外家屬匯款予在台僑生或國際學生）。

### 範圍摘要

| 範圍內 | 範圍外 |
| --- | --- |
| 註冊與身分驗證、收款人管理 | 借貸／預支薪資 |
| 匯款流程、費用與匯率揭示 | 帳單代收代付／儲值 |
| 台灣端資金存入（超商／ATM） | 台灣境內轉帳 |
| 撥付：銀行存款、行動錢包、代理現金領取 | 其他匯款通路（如菲律賓、泰國） |
| 額度追蹤、交易紀錄與到帳通知 | 加密貨幣／穩定幣清算 |
| 入金流向（僑生／國際學生） | 完整數位銀行功能、雇主薪資系統整合 |
| 後台：身分審核、洗錢防制監控、結匯申報 | 自建現金保管與實體代理網絡 |
